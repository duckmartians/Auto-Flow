# AutoFlow Extension — Manual Installation (Chrome / Edge)

This extension is not on the Chrome Web Store, so it is installed manually as an "unpacked" extension. It takes about a minute.

[![Download Extension](https://img.shields.io/badge/Download-Extension%20(.zip)-blue?style=for-the-badge&logo=googlechrome)](https://github.com/duckmartians/Auto-Flow/raw/main/auto-flow-extension_10.8.58.zip)

Or download directly: [auto-flow-extension_10.8.58.zip](https://github.com/duckmartians/Auto-Flow/raw/main/auto-flow-extension_10.8.58.zip)

---

### 1. Download & Unzip this file
- Download the zip file using the download button above.
- Right-click the downloaded `.zip` file and select **"Extract All…"**. You will get a folder containing the `manifest.json` file.

### 2. Open the Extensions page
- On **Google Chrome**, enter the following address into the URL bar:

       chrome://extensions/

   (On Microsoft Edge, use:  edge://extensions/ )

3. Turn on Developer mode
   Flip the "Developer mode" switch in the TOP-RIGHT corner of the page.

4. Load the extension
   Click "Load unpacked", then select the UNZIPPED FOLDER
   — the folder that contains "manifest.json", NOT the .zip file itself.

5. Done
   The extension now appears in the list. Click the puzzle-piece icon in
   the toolbar and pin it for quick access (optional).

Updating to a newer version
---------------------------
   1. Download and unzip the new .zip (replace the old folder).
   2. Go to chrome://extensions/ and click the circular RELOAD icon
      on the extension's card.

Notes
-----
   - Keep the unzipped folder where it is — deleting or moving it removes
     the extension from Chrome.
   - "Developer mode" must stay ON for an unpacked extension to keep running.
